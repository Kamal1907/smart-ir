About SmartIR

SmartIR is a prototype smart institutional repository designed and implemented as part of a master's research project on research publications at the University of Lagos. It extends the functions of a conventional repository with automated metadata quality control, duplicate detection, controlled vocabularies, full-text search with faceted browsing, usage analytics and OAI-PMH interoperability.

Standards

Dublin Core Metadata Element Set (DCMI); OAI-PMH 2.0 with the oai_dc format; ISO 8601 dates; ISO 639-1 language codes; COAR-aligned access rights vocabulary.

Workflow

Depositor submits, the system checks metadata in real time, a librarian reviews, then approves, returns with a note, or withdraws. Every action is written to an audit log.
